# QQ Markdown 长回答

QQ 回答使用原生 Markdown。长回答按不超过 1500 UTF-8 字节自动分段连续发送；跨段代码围栏会补齐关闭标记并在下一段重新打开，正文顺序完整保留。

每个房间的投递串行。新鲜的被动回复最多使用五个发送槽位；回答分段超出余量或回复窗口已过期时，整批改为主动发送并附提问者和问题标识。每段记录发送方式、平台消息 ID、可选引用索引与回执。遇到拒绝、未知回执或进程关闭时停止余下投递；重启不自动重发。

原始模型 Markdown 作为一次 AI 回答进入滚动历史。完整投递正文快照单独保存，`/result` 可按本人和当前会话领取，不重新调用模型，也不拼接代码围栏已经补齐的发送分段。`/page`、摘要入口和消息按钮不再提供。

schema v17 的 `answer_documents`、`answer_page_views` 及旧引用索引继续保留，只供历史记录读取和引用解析。新投递使用 `answer_documents.rendered_body` 保存完整正文；摘要为空、页面列表为空数组，也不创建页面回执。
