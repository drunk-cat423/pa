# 上下文缓存专项

本页是现有 repo harness 的缓存检查入口：开发时防止前缀回退，拉取仓库时通过既有只读巡检发现真实缓存骤降。不另设全局 Skill、CI、定时器或常驻告警服务；无人运行检查时不会主动通知。

## 必须保持的契约

前台渠道最终发出的请求按准备/回答分别采用固定 system 协议；回答阶段包含三种模式的固定定义，本轮阶段、模式、链接、研究对象和纠错等动态控制信息放在历史之后。当前问题、画像、身份和时间仍按原有规则组装，历史只增量追加，压缩成功后才更换摘要与检查点。

Pi 会把 system sections 合并到开头，不能仅凭内部 transcript 中的位置判定前缀稳定。提示、工具投影、上下文或 Pi 版本变化时必须检查本地 HTTP 服务实际收到的 SDK 请求：同阶段的模式和本轮控制值变化不应改写 system，长历史仍位于动态控制块之前。准备与回答阶段的工具过滤、强制 `tool_choice`、真实权限和次数限制仍由程序执行；不为了相同工具目录放开写入阶段。两个阶段本来具有不同工具目录，各自形成缓存前缀，不为跨阶段 system 相同而在每次请求重复两套完整规则、挤占小窗口容量。

CLI、后台研究和专用归属核验有各自协议，不宣称这些请求与前台共享同一前缀。固定协议或工具契约升级会产生新前缀，首次命中下降本身不证明代码故障。

## 修改时运行

```powershell
node scripts/repo-check.mjs cache --list
node scripts/repo-check.mjs cache
```

入口复用现有编译与离线回归，只使用临时 SQLite 和本地 HTTP SSE，不加载生产 `.env`、不请求真实模型或 QQ。专项验证这次已确认的事故：三种回答模式及动态控制变化后，最终 system 和旧历史前缀仍稳定；工具仍按阶段受限；巡检能够区分阶段、缺失用量、冷启动及真正骤降。测试依据登记于 `test/regressions.json`。

这些回归证明请求结构和诊断程序行为，不伪造供应商缓存命中率；不得用 Mock 返回的 usage 声称实际性能提高。量化改进应先报告共同前缀/历史保留长度，真实命中率需要上线后的自然请求复核。

## 运行中检查

```powershell
# 已配置本机SSH目标后，同时同步代码和巡检；不自动发布。
node scripts/ops/sync-and-check.mjs
```

缓存统计随最近窗口的诊断汇总输出，专项最多取最近160次已完成的渠道 chat 调用；数量、截断与时间边界在报告中标明。明确标记的 research/cli 排除；旧记录无 `contextKind` 时按 legacy chat 处理，不能确认全部属于渠道。口径如下：

- 实际输入 = SDK `input + cacheRead + cacheWrite`，命中率 = `cacheRead / 实际输入`；阶段汇总按 token 加权，不对各次百分比求简单平均。输出 token 不进入分母。
- 只比较同作用域、供应商、模型、阶段的有效样本，不用准备请求与回答请求互相比。大输入至少50,000 token、当前命中率低于20%，且上一个同类有效样本至少80%时报告骤降。首次冷缓存无此基线，单独计数；未知或缺失 usage 不当作零。
- 最终 `cachePrefix` 指纹可说明 system 或工具定义是否变化；旧日志没有指纹时只能标记未知。指纹相同仍低命中时保留供应商缓存失效等可能性，不擅自定因。
- `contextWindow` 来自实际模型窗口，缺失时不把输出上限当作窗口。输入占用比例与包含输出预留的准入估算是不同口径。
- 已完成的 chat 缺少有效阶段元数据时，记录 `missingStage` 并将缓存统计标为 `partial`，提示检查不完整，不能当作没有调用。已知研究、CLI 和专用归属核验仍单独排除。旧指纹缺失只限制归因，不隐藏已知的高到低变化。

默认只读取诊断索引元数据，不读取请求/响应、聊天、画像或密钥。报告写入忽略的 `.local/ops/`，不进入 Git。出现 attention 后先看 callId、时间、阶段、用量、指纹变化及是否刚发布；低命中不自动触发模型重试、压缩或服务重启。

需要继续定因时，按[日志说明](logging.md)显式读取有关请求，核验原证据哈希，再比较同阶段前后最终 system、工具定义与历史共同前缀。只分享结构和哈希，不把生产正文放进测试或 Git。DeepSeek 的缓存匹配与保留属于供应商行为，参考[官方缓存说明](https://api-docs.deepseek.com/guides/kv_cache/)，即使布局稳定也不保证100%命中。
